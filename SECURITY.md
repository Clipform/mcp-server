# Security policy

## Reporting a vulnerability

Email **security@clipform.io** with a description of the issue, steps to reproduce it, and any proof-of-concept material. Please don't open a public issue for a security problem.

We aim to acknowledge a new report within a few business days, and we'll keep you updated while we investigate and fix it.

## Scope

- This MCP server (`@clipform/mcp-server`) and the hosted MCP endpoint at `mcp.clipform.io`, including its OAuth flow.
- Clipform's production services: `clipform.io`, `www.clipform.io`, `app.clipform.io` and `api.clipform.io`.

Denial of service, social engineering and automated scanner output without a demonstrated, exploitable finding are out of scope.
